# 体裁核心机制（精要版）

> 构思/验证大纲时对照：核心梗三层、微创新、冲突网络、金手指匹配、事业/爱情线、卖点偏移检验。本精要只列核心可执行规则；完整决策路由/偏离案例/改写范例/CP分级见 get_craft_doc('genre-mechanics')。

## 核心梗三层递进（主题→题材→情绪）
- 一代主题（立意，防止偏离）；二代题材核心（独有吸引力，筛选读者）；三代核心情绪（期待→满足的完整链条，不是爽点形式）。
- 剧情顺序：核心卖点 → 情绪套路 → 具体剧情。
- 核心梗 = 金手指最有趣的使用方式 + 读者最想看的爽点模式（可平替：女帝→朱元璋→嬴政）。
- 偏离题材核心 = 抛弃吸引读者的最大依仗，在读直线下降。

## 每章循环检查（断期待=弃书信号）
每章必备三选一：①核心梗期待点 ②核心梗爽点 ③介于两者之间。既无期待也无爽点、前一爽点已结束且没拉起新期待 = 断期待（读者觉得书"没了灵魂"开始弃书）。

## 微创新（≤3 个）
范围：人物 / 人物关系 / 情节，最多 3 个点，不超模板边界。
五法：精炼（套路做到极致）/ 升级（框架不变元素升级）/ 加料（加新元素）/ 反套路 / 组合。

## 冲突网络（三层同时运作）
- 纵向（上下级：控制/反抗/师徒）、横向（平级：理念/资源/竞争）、交叉（A-B、B-C 推出 A-C）。
- 编织顺序：定地图→阵营→角色→填纵+横→推交叉。

## 金手指匹配世界观
- 极道流（阶级固化/环境恶劣）→ 无条件加点；常规升级流（换地图）→ 碎片/解锁；轻松日常流（低压迫）→ 人际/种田。
- 功能单一金手指只适配强压迫世界观，硬用要补丁。

## 事业线/爱情线
- 事业线是骨架，爱情线是藤蔓，天花板取决于事业线。主线要落成一件事（不是"升级"本身）。
- 九一开：事业为主的文爱情线 ≤1 成，且必须服务事业线。
- 爱情线四阶段：萍水相逢→怦然心动→暧昧升温→确认关系。推进要拉扯（推进与拉开交替，不能只拉近）。
- 男频：男主追事业→无意英雄救美→女主倒追（不写男主追女人为女人付出）。

## 爽点阈值递升
后一个爽点须在「影响力范围/人物层级/收获价值/认知颠覆」至少一维超过前一个。失效信号：读者对相似规模爽点不再反应。

## 卖点偏移检验（防崩盘三检查）
1. 一句话说清核心卖点的目标情绪？
2. 卖点能拆出 ≥5 个不重复的剧情展开方向？
3. 卖点所需核心能力可由现有写作方法论覆盖？

## 质量检查清单
- [ ] 核心梗一句话说清（读者翻开最想看什么）
- [ ] 三层递进齐全（主题/题材核心/核心情绪）
- [ ] 每章不离梗（无断期待空白章）
- [ ] 微创新 ≤3 个
- [ ] 冲突三层铺满（纵/横/交叉各 ≥1 在运作）
- [ ] 金手指匹配世界观
- [ ] 爽点阈值递升
- [ ] 事业/爱情线比例（爱情 ≤1 成且服务事业）
- [ ] 基调贯穿全文、卖点不偏移（书名/简介/前3章与实际内容一致）

## 何时查完整版
- 需要偏离核心梗的典型作品案例（后果/改善方向）、悲剧命运改写法、CP 行为分级体系、脑洞错位系统、男女频核心梗差异等细节时。
