# 读者画像与题材适配（精要版）

> 读者心理需求、题材生命力、跨平台适配、书名/简介技法、代入感管理。选题定位时对照。本精要只列核心可执行规则；完整决策路由/平台细则/书名示例见 get_craft_doc('genre-readers')。

## 读者心理需求（从爆款反推）
- 提炼爆款核心剧情元素 → 框定读者画像 → 推测深层心理需求 → 对照目标读者真实生活验证。
- 写作前先问：目标读者现实生活中**最缺什么、最想要什么**？情绪需求深度决定作品天花板。
- 情绪根源来自「不公平」和「为什么」：区别对待 → 读者觉得不公 → 情绪根源。
- 网文通用深层需求：被认可 / 被理解 / 被尊重，表面「打脸」只是外壳。

## 题材生命力
- 按**当前样本**验证（不把历史经验当当前事实）。阶段：新鲜期（提炼创意）/ 成熟期（稳定交付边界期待）/ 疲劳期（必须新切入点）。
- 无法确认阶段按成熟期：保守满足边界期待，微创新 ≤3。
- 跟风只复用结构功能位，不复刻剧情内容。

## 跨平台适配（同一题材不同平台写法不同）
- **刺猬猫**：整活+人设，同人/二游基础，少打斗多日常。
- **起点**（非轻小说）：正常剧情推进+代入感。
- **番茄**：强情绪/噱头/爽感直给，书名决定 80% 流量。
- 必须用目标平台样本校准读者期待/节奏/雷点，不能 A 平台经验硬套 B。

## 代入感
- 代入感高度重叠爽感：越代入越爽；代入感低时主角做什么都不爽。
- 塑料感来源：仙侠不仙 / 武侠不侠 / 画风撕裂（仙侠搞科研）。去塑料感=让世界像真实存在。
- 商业化：非核心情绪的个人表达 ≤5%、不打断叙事；所有私人表达服务核心卖点。

## 书名命名（3 秒抓人）
- **身份法**（覆盖约 1/3）：[高位身份]+[反差行为]；[低位]替[高位]做[超预期事]。
- 其他：掉马甲型 / 逼格起名 / 反义词反差 / 主线+爽点。
- 番茄：噱头优先吸量第一；起点：轻度反差+金手指+主线。

## 简介/文案（安全感+钩子）
- **四段式成功型**（情境→冲突→行动→成功，最通用，给安全感）。
- 三段式行动型（留悬念，事业线突出）/ 二段式悬疑型（造好奇）/ 失败型（虐感，追妻火葬场）。
- 文案须体现主角主体性 + 至少暗示会成功；书名/简介/内容三位一体（货不对板劝退）。

## 质量检查清单
- [ ] 读者画像明确（一句话说出目标读者缺什么）
- [ ] 深层需求对位（核心情绪匹配读者深层需求，非自嗨）
- [ ] 题材生命力（当前样本确认阶段）
- [ ] 平台适配（针对目标平台调整）
- [ ] 边界感（素材/知识/篇幅支撑题材）
- [ ] 书名 3 秒抓人
- [ ] 简介有安全感+钩子
- [ ] 代入感无塑料感（世界观自洽、画风统一）
- [ ] 书名/简介/内容三位一体
- [ ] 金手指与主角生活/职业关联

## 何时查完整版
- 需要某平台详细细则（刺猬猫/番茄/起点）、书名命名示例库、简介组合策略、历史文红线、玄幻三大核心（代入/期待/认同）等细节时。
