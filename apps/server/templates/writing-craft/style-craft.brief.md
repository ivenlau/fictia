# 写作技法（精要版）

> 教 agent 把文字写成镜头、用动作而非形容交付情绪、并避开毒点。本精要只列核心可执行清单；完整判定标准/范例见 get_craft_doc('style-craft')。

## 核心规则
- 采用镜头式写作：你是跟在主角身后的摄像机，只写能看到/听到/闻到/摸到的，不写"他心里想""他感到"。
- 用动作和神态代替情绪描述：不写"他很紧张"，写"他的手在抖"；离底层情绪越远的表达越高级。
- 每句对话必须至少满足一项——推进剧情 / 塑造人物 / 制造张力；用动作打断长对话，每次说话不超过3句。
- 每个段落就是一个镜头，远景/中景/近景/特写交替；按动作或信息变化断段换行，手机屏幕优先。
- 至少调动两到三种感官写"感受到什么"，且五感必须服务情绪（恐惧写冷暗静，兴奋写亮快响）。
- 白描为主：最少的字 + 最准确的动词名词；长篇不需要精致文笔，目标是让读者忘记在看字、直接看到画面。
- 长短句交替控节奏，连续三短句后接长句；环境描写必须有角色交互，否则不写。
- 主角目标清晰、行为可理解，叙事立场必须站在主角一侧；一本书随时保持两条以上期待线。

## 关键清单
- 视角禁忌：禁用全知叙述、上帝视角、心理分析混入；网文默认第三人称有限视角。
- 高危词汇：仿佛、犹如、一丝、一抹、深吸一口气、缓缓、不禁、眼中闪过、嘴角勾起、眉头微皱、不容置疑、不易察觉。
- 高危句式：禁用"……，带着……"（如"他说，带着一丝无奈"）；禁用"他/她知道……"（直接展示，不告诉）；禁用陈词滥调/万能比喻。
- 对话标签：避免高频/公式化标签，普通"说"可保留，机械重复时用动作神态替代。
- 情绪表达禁最低两级：不直接写"xx愤怒/伤心"（最低），也少用思想层"xx暗骂"，改用神态或动作。
- 水分检查：删掉某段后读者不困惑 = 该段多余；有害的水包括重复已知信息、无意义环境描写、角色自言自语。

## 何时查完整版
- 需要具体的改写范例库、机位交替细则或对话情绪五级递进示例时。
- 设计开篇黄金三章、做定调三层次（情绪氛围/故事走向/价值观）和期待线循环管理时。
- 需要五大毒点方向的题材适配建议、视角选择决策表或文笔阶段重要性判断时。
