# 角色设计方法论（精要版）

> 三层标签反差/九维框架/配角功能化/群像/代入感。角色设计时对照。本精要只列核心可执行规则；完整决策路由/桥段模板/循环写法见 get_craft_doc('character-design')。

## 三层标签反差人设（核心）
- 第一层**身份标签**（外界看的身份）+ 第二层**表现标签**（展现给外界的行为）+ 第三层**内核标签**（真正内心）。
- 三层间制造反差 = 立体感；身份/表现可相似（强化刻板印象），**内核必须反转**。反差越大，「亮牌时刻」越震撼。
- 用行为对比体现，不直接描述（身份：豪门弃妇；表现：被骂不还口；内核：悄悄录音转移财产）。
- 关系进入亲密期后，早期行为反而做不出来（行为退化 = 感情深化）。

## 人设执行规则
人设 ≠ 人物设定表（身高体重爱好堆砌）。人设 = 围绕「灵魂/特殊人格」的**功能性设计**，服务戏剧张力，以人格驱动行为。只有外貌信息没有功能性设计 = 重做。

## 配角功能化
- 配角能力为主角所用，脱困靠主角帮；光环保略弱于主角。
- **白手套角色**：替主角说话 / 发狠 / 绝对维护 / 粗中有细 / 适时搞笑。
- 立体 vs 扁平：不是所有角色都立体化；扁平化保持神秘反而更强（「洗白弱三分，黑化强三倍」）。
- 设计配角先定功能，再从六维反差选 1-2 维贴标签。

## 人设关联分层
- **强关联**（影响剧情/核心梗，每角色 ≥3 个）：实力/钱财/人脉/背景。
- **中关联**（配角强关联，不抢主角）：功能性 + 辨识度。
- **弱关联**（个人偏好，丰富厚度）：不限，不喧宾夺主。

## 九维人设框架
基本信息 / 性格（反差）/ 爱好习惯（记忆点）/ 人际关系（复杂造冲突）/ 背景 / 成长弧线 / 对比反差 / 价值观态度 / 人物小传。
- 成长弧线三阶段：小我（虚构自己）→ 自我（真实夹缝）→ 他我（成熟，别人眼中即追求）。
- 情绪公式：满足（认同）→ 打击（同情）→ 怀疑（共鸣）→ 心痛（共情）。

## 凸显人设 + 记忆点
- 抓最突出特质集中火力；用行动展现不用旁白；反差碰撞造张力（控制尺度，太大劝退）。
- 每人物至少一个特别突出的特征 = 记忆点（哪怕剧情不推进，几人聊天读者也爱看）。
- 高情商通过具体剧情体现（察言观色/临场应变），不旁白夸赞；每桥段至少一个「预期尴尬但主角化解」的反转。

## 群像 + 节奏
- 每角色出场都要有功能（无功能的舍弃）；关系有层次（引路人/对手/伙伴/障碍）；不同角色不同说话风格。
- 高人气角色每 3-5 章出场一次，每次有新信息/功能；不感兴趣的自然下线。
- 角色池编织：以角色带角色（女主讨喜 → 写她家人/闺蜜 → 喜爱延续）。

## 代入感
- 核心：情感链条不断裂；断裂标志 = 读者开始用现实逻辑评判情节。
- 共情三层次：表层（经历类似）→ 深层（情感类似）→ 认同感（价值观一致）。
- 救猫咪情节（开头强调人设某面）/ 共情前提（暴露弱点困境）/ 合理化虑点（缺钱等人人懂的困境）。
- 避免破坏代入感：不可理解的选择 / 大段设定说明 / 节奏拖沓 / 三观严重偏离。

## 安全感把控
- 紧张题材（极道流）不要给主角太强靠山（安全感拉爆 = 危机感消失 = 核心情绪偏移）。
- 精力有限时情节第一，世界观只是加分项。

## 质量检查清单
- [ ] 三层标签齐全，至少一层反差
- [ ] 强关联设定 ≥3 个
- [ ] 人设是功能性设计（非外貌堆砌）
- [ ] 配角有明确功能，不抢主角风头
- [ ] 每角色至少一个记忆点
- [ ] 配角出场都有功能（无水分）
- [ ] 不同角色不同说话风格/行为特征
- [ ] 主角错误在可原谅范围（不可抗力/信息差可；蠢/圣母/与实力不匹配不可）
- [ ] 反派有自己逻辑追求（非纯粹恶）
- [ ] 人设言行前后一致（不崩）
- [ ] 代入感情感链条连续（不被设定说明打断）
- [ ] 安全感匹配题材（紧张题材不超强靠山）
- [ ] 高情商桥段通过具体剧情展现（非旁白夸赞）

## 何时查完整版
- 需要「向人设深化 vs 故事深化」判断表、循环写法（一个情节写 5 章）、金手指绑架人设法、以梗为中心塑造、职场思维关系结构、关系四阶段细节等时。
