# 装逼打脸与战斗（精要版）

> 装逼打脸框架/爽点释放/打斗/战斗描写。设计装逼打脸/战斗场景时对照。本精要只列核心；完整框架/范例见 get_craft_doc('style-combat')。

## 爽点释放到位法则（核心铁律：该爽不爽比毒点还毒）
- 先确认场景承诺的爽点，保证释放强度匹配铺垫强度。
- 放了底牌，反派要受对应压制（破防/羡慕/扭转战局）；金手指效果展示清楚。
- 寸止/拉扯可以，但**别让主角委屈**；甚至可牺牲部分合理性换情绪顺畅。

## 装逼打脸框架（人际关系驱动）
核心 = 被环境认可的鄙视链（学校=成绩 / 职场=业绩 / 神豪=钱 / 古代=文采）。
1. 铺垫人际关系（建立主角与配角联系）。
2. 构架舞台（群众层 → 中间层 → 核心层）。
3. 层层传递震惊（主角行动 → 第一层震惊 → 核心层 → 反向传回群众）。
- 装逼前必须铺设传递通道；闭环 = 高潮后众人态度转变。
- 二级结构化：震惊不只是「好厉害」，而是「这跟我有关系」（改变角色利益/计划）。

## 三种装逼 + 三种打脸
- 装逼：基础（直接装）/ 温酒斩华雄（侧面压再装）/ 狠压式（压到上头再装，最强）。
- 打脸：愤怒式（单层次，做了令读者上火的事）/ 循环打脸（同剧情打三四次递进）/ 狠压式（压越狠打越爽）。
- 愤怒式与瞧不起式是两种不同压点，不能写串。

## 打斗/智斗
- 打斗 = 表演，是展示收获的舞台，服务爽点；能秒杀就秒杀。
- **心-体-技三维**：心（意志/心态，以弱胜强关键）/ 体（力量敏捷装备）/ 技（武技/法术/法则）。
- 战斗设计：铺垫先行 → 预判结局 → 构建爽点 → 拉开维度（新技能对比/对方给错觉/旁观震惊）→ 反转。
- 智斗 = 信息差博弈；一环套一环要自洽；玩转人性比蛮力有效。

## 战斗描写三板斧（玄幻/修仙/武侠）
- 核心：男主很牛逼（无论参与旁观）。
- 结构：气势对拼 → 语言交锋 → 出招 → 敌人防御 → 碾压/秒杀 → 路人惊叹。
- 反派先铺垫极强，再被秒杀（反差即爽感）。
- 修仙斗法逼格四要素：时间（大尺度）/ 数字（可量化）/ 意识流元素 / 用典。
- 升级路线：拳打脚踢 → 法术对轰 → 规则机制对抗（机制难审美疲劳）。

## 舞台搭建法
- 大小 = 观众数量（室友 → 直播间万人 → 全世界）；高度 = 对手身份+比赛重要度（排位 → S 赛决赛）。
- 每次装逼检查：舞台还能更大更高？在不崩前提下观众能拉多少拉多少。

## 无敌文铁律
主角登场不能拖拉（杀伐果断 + 战力前置无敌 = 天然期待）；不拖拉 = 读者形成「主角登场就大杀四方」期待。

## 情绪调动三阶法（长期）
共鸣炸弹（唤醒读者情感）→ 见证者（感受角色付出）→ 参与者（引导读者以为自己付出了很多，越投入越离不开）。

## 质量检查清单
- [ ] 爽点到位（底牌放出反派被压制，没被反打）
- [ ] 主角不委屈（寸止可以，不被羞辱/打脸）
- [ ] 铺垫充分（装逼前有传递通道）
- [ ] 震惊分层（基于角色利益不同反应，非统一「倒吸凉气」）
- [ ] 舞台够大（观众/对手匹配爽点高度）
- [ ] 战斗服务爽点（不为写打斗而写）
- [ ] 无敌文主角不拖拉
- [ ] 情绪节奏急-缓-急交替（非匀速）
- [ ] 以弱胜强有逻辑（信息差/环境/心理，非运气）
- [ ] 装逼闭环（高潮后态度转变）
