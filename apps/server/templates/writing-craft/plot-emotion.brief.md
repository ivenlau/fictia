# 情绪体系操作手册（精要版）

> 主角与对手递进对抗、爽点倒推、情绪升级与对比，用情绪波动驱动读者欲望。本精要只列核心可执行清单；完整判定标准/范例见 get_craft_doc('plot-emotion')。

## 核心规则

- 角力而非碾压：每次小角力主角稍占上风，最后大胜利；层级递进"对三→对四→对A→对2→王炸"。
- 升级线与主角反应线分开管理：实力升级不自动改变主角的从容，面对低级挑衅不被牵着走（暴怒反击=毒点，毫不在意=逼格）。
- 爽点设计必须倒推三步：先定爽点类型（六种之一）→ 再设计期待点 → 最后补铺垫，设计章纲也按此顺序。
- 负面情绪逐步加码到饱和再转化为正面，不要一次到位；不要拉长单个爽点的铺垫，而是多想几个爽点。
- 用层次划分法制造连锁震惊：当场观众震惊→别处观众震惊→专家震惊→配角间信息差抹平→再震惊。
- 同套路（如英雄救美）反复用不腻，腻的是结构不变；每次换场景/换对手/加新情绪即不算重复，且每次复杂程度和收获螺旋上升。
- 误解消除规则：对事业线/爱情线有负面作用的误会必须消除；无负面或有正面作用的可不消除。

## 关键清单

- 六种爽点类型：能力碾压 / 目标达成 / 收获盘点 / 态度转变 / 隐藏身份掉马甲 / 情感圆满度。
- 装逼层级：日常小装逼（距下个大爽点远时维持耐心）/ 核心爽点（切在主线）/ 偏离爽点（应避免）。
- 情绪模块卡片：修罗场卡、倒计时卡、恩怨情仇卡（大/中戏剧单元）、双重身份卡、特殊对待卡、好感变化卡、误解卡。
- 节奏阈值：大高潮 7-10 天完成（一天双更，14章），超过10天读者易反感；小高潮 3 天左右；高潮后加 1-2 章日常过渡。
- 循环结构：公众期 1 章人设+2 章铺垫+1 章打脸+1 章反响；VIP 1-2 章人设+5 章铺垫+1-2 章打脸+1 章总结。
- 驱动读者欲望四步公式：生产诉求 → 给予希望 → 努力解决 → 得偿所愿。
- 梗的四段式：发生 → 发展 → 转折 → 高潮，缺转折直接跳高潮为大忌。
- 卡片可叠加：核心梗卡 + 关系卡 + 限制卡 = 完整剧情单元。

## 何时查完整版

- 需要具体的情绪模块卡片设计要点、戏剧单元五级提炼法（零级到四级）或换壳重构范例时。
- 需要叙事元素卡（工具人/迷之少女/失能/关系/秘密等12张）与结构技法卡（差异评价/戏剧三角/翻弄风云/解谜）的完整定义与组合规则时。
- 需要完整的"质量检查清单"逐项核对某段剧情，或决策路由表定位具体写法时。
