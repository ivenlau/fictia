# 商业创作核心方法（精要版）

> 卖点/节奏/金手指/期待感/六大模块/留存。大纲设计、选题定位、商业化时对照。本精要只列核心可执行规则；完整决策路由/实例/章纲层级见 get_craft_doc('commercial-methods')。

## 商业网文六大核心模块
1. **定调（黄金三章）**：令人不安的处境 + 亟待提升的地位 + 充满希望的外挂 + 可展望的美好未来。
2. **金手指（简单是核心）**：信息挂（最优，不易失控）/ 加速升级挂 / 物体调用挂；游戏化面板一眼懂最好。
3. **角色（脸谱化）**：重要角色多标签，行为基于标签；充满算计（送资源/被打脸/当向导，分工明确）。
4. **节奏（循环嵌套）**：确立目标→行动→完成→提升→新目标；对抗审美疲劳从数值对抗转机制对抗。
5. **爽点**：生产诉求→给予希望→努力解决→得偿所愿；先「不爽」再拿掉不爽。
6. **冲突与悬念**：冲突可套路化，悬念需精巧；章末营造「即将达成」临界状态。

## 卖点四步法
思考（全书/书名/简介/每段剧情卖点）→ 设计（围绕卖点扩散）→ 细化（对位读者群/风格）→ 表现（每章一个目的词，盯章纲写）。
- 卖点表达：让读者自己发现（发现比告知爽十倍）；三层递进（开头暗示→中间深化→高潮爆发）。
- 书名=第一道门，简介=第二道，开篇=第三道，层层传递并兑现核心卖点。

## 三种期待感（合一=不崩之书）
- **剧情期待**（吊胃口，偶尔满足）：大目标 + 过程挖坑 + 立角色。
- **主题**（每天甜头，持续满足）：每章给读者想要的，主题不偏。
- **新鲜感**（间歇刺激）：世界观矛盾新鲜 + 剧情形式多样。

## 节奏法
- 大高潮 7-10 天，小高潮 3 天，高潮后 1-2 章日常过渡。
- 拖沓信号：连续 2 章无目标推进/阻碍升级/新信息 → 下章提高冲突密度。
- 过快信号：连续 2 章只爆点不留反应余波 → 插承接场景（须推进关系/伏笔）。
- 中后期追订下降两因：爽点重复（审美疲劳）/ 长远期待缺失 → 大纲先定结局，围绕结局设计中后期爆点。

## 金手指原理
- 故事流程：激励→欲望→目标→行动→阻碍→克服→奖励。金手指可替换任一环节（但要有限制保证结构完整）。
- **金手指+矛盾=剧情**：太强+矛盾不够=无聊；太弱+矛盾太强=焦虑；最佳=刚好解决当前矛盾→暴露更大矛盾→层层递进。
- 金手指反馈：给出后必须有即时变化；契合主角职业或作打开困境的钥匙。

## 留存=情绪+饥饿
- 情绪：快速代入→沉浸→共鸣。
- 饥饿：信息差在读者视角植入问号；剥洋葱（简介核心悬念→章首小问号→章末卡关键信息）。
- 开篇：300-500 字交代处境+危险来源+破局希望；主角不能完美（否极泰来的开端）。

## 读者需求层次（马斯洛对应）
生理→肉文/后宫；安全→无敌/系统；社交→后宫/团队；尊重→爽文/打脸；自我实现→升级/探索。**跨层满足=爆款潜力**。

## 质量检查清单
- [ ] 核心卖点一句话说清
- [ ] 卖点无偏移（每十章自检「当初吸引读者的卖点还在吗」）
- [ ] 金手指简单（一眼懂）+ 与矛盾匹配
- [ ] 三种期待线并存（剧情/主题/新鲜感）
- [ ] 节奏有标尺（大高潮 7-10 天/小 3 天/高潮后过渡）
- [ ] 升级节奏合理（不太快=失去期待，不太慢=失去耐心）
- [ ] 主题统一（随机翻一章，情绪指向全书核心）
- [ ] 书名/简介/开篇三道门
- [ ] 章纲有目的词（铺垫/高潮/爽点/打脸/人物塑造/设定）
- [ ] 留存双引擎（情绪 + 饥饿）
- [ ] 拉长板非补短板（核心卖点/目标情绪/最高频爽点）
