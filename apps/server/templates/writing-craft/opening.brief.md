# 开头设计（精要版）

> 写前 3 章时按此清单校验开篇吸引力。本精要只列核心可执行清单；完整判定标准/范例见 get_craft_doc('opening')。

## 核心规则
- 从故事最精彩、最有冲突的地方写起；300 字内主角登场，1000 字内出现爽点或期待点。
- 主角三种开局状态选一：身处危机 / 令人羡慕 / 被丢入陌生环境。
- 前 3 章必须全部完成三个基点：人设基点（性格+处境→代入感）、切入点基点（第一个冲突/机遇→紧迫感）、金手指基点（独特优势→期待感）。困境型先人设，优势型先金手指；切入点必须跟主线强相关。
- 第一章必须明确主角目标 + 本文卖点；第一个冲突影响要重大，事先点明解决的好处和不解决的坏处。
- 背景信息分批释放，优先级：危机感 > 人设 > 金手指暗示 > 世界观；每次释放服务于当前情绪目标。
- 两个紧张场景之间可缓和，但缓和 ≠ 无冲突；战斗/紧张场景中必须穿插情绪（恐惧、愤怒、决心）。
- 期待感公式：情绪 + 情节（人设+动机）+ 信息差，三者缺一则不足。
- 重大事件不能写得像闹着玩；创意点必须转化为具体剧情冲突，不能停留在概念。

## 关键清单（开篇必查）
- [ ] 主角身处危机/令人羡慕/被丢入陌生环境之一
- [ ] 300 字内登场、1000 字内出爽点或期待点
- [ ] 前 3 章完成人设/切入点/金手指三个基点
- [ ] 第一章交代主角目标 + 本文卖点
- [ ] 第一个冲突影响重大且利害点明
- [ ] 背景融入冲突、信息分批释放，节奏不拖
- [ ] 书名/简介/开篇三者统一，开篇呼应书名承诺

## 绝对禁止（硬性禁忌）
- 大段背景介绍、天气/风景开头（除非反差极大）
- 前 3 章出场 3 个以上主要角色（信息过载）
- 序章/楔子/引（除非叙事为主、极简短且与第一章逻辑紧密）
- 插叙/切视角/回忆梦境（正叙为主）
- 世界观详细解说（至少等到第一个一级结构结束）

## 何时查完整版
- 选具体开头策略/题材模板时（危机/悬疑/反转三策略，及都市脑洞、豪门、宅斗、玄幻、青春、年代等逐题材范例）→ get_craft_doc('opening')
- 需要开头字数分配（七步法）或噱头三分法（事件/金手指/人设噱头）写法细节时
- 需要平台差异化指标（番茄/起点/晋江的爽点密度与节奏取舍）或循环套路参考时
