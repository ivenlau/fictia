# 章级钩子（精要版）

> 为每章开头与结尾选择并写出能驱动翻页的钩子。本精要只列核心可执行清单；完整判定标准/范例见 get_craft_doc('chapter-hooks')。

## 核心规则
- 章首前 100 字必须落钩，禁止用风景/天气/背景介绍开局。
- 章尾必留一个让读者想翻下一页的悬念，长度约 100 字，点到即止不拖沓。
- 钩子强度匹配章节阶段：第 1 章必强、2-3 章与高潮前强、中期日常可中、大结局收束。
- 连续两章不得用同一种钩子，需换型避免重复。
- 写爽点时落点放在「大众逻辑 vs 主角逻辑」的冲突落差上，落差越大越爽。
- 打脸前必须前置「小无敌」铺垫（道具/实力/人物就位），否则嘲讽变虐主；铺垫比打脸更重要。
- 打脸对象层级决定爽感层级：路人甲震惊不叫爽，有分量的人震惊才叫爽。
- 看点（吊期待）与爽点（满足期待）一一对应，前面铺多少后面爽多少。

## 关键清单
- **章尾钩子 13 式**：突然揭示 / 紧急危机 / 未完成动作 / 身份反转 / 两难抉择 / 神秘物品 / 倒计时 / 承诺威胁 / 离奇消失 / 隐藏含义 / 意象钩子 / 回声钩子 / 留白钩子。
- **章首钩子 7 式**：悬念对话 / 闪前碎片 / 倒计时 / 神秘独白 / 反差场景 / 未完成动作 / 意象预示。
- **章尾选型（按本章情绪）**：悬念未知→揭示/物品/留白；紧迫危机→危机/倒计时/未完成；反转真相→身份反转/隐藏含义/回声；情感关系→两难/承诺威胁/情感转折；氛围日常→意象/离奇消失/信息差。
- **装逼打脸节奏（公众期 5 章循环）**：人设 1 → 铺垫 2 → 打脸 1 → 善后 1；VIP 期可拉长至人设 1-2 / 铺垫 5 / 打脸 1-2 / 善后 1。

## 何时查完整版
- 需要套具体公式与改写范例（系统激活型/悬念预知型/截断型/选择型等十种章尾模板）时。
- 拿不准某类钩子的判定标准或示例写法时。
- 大纲阶段需为整本书多章批量规划钩子类型与强度配比时。
