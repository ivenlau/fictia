# 情绪弧线操作手册（精要版）

> 写故事时选弧线、控制节奏、调动情绪的操作手册。本精要只列核心可执行清单；完整判定标准/范例见 get_craft_doc('emotional-arcs')。

## 核心规则

- 选弧线时用一句话定位情绪效果（虐完翻盘 / 甜完刀死 / 多反转 / 层层打脸 / 隐忍爆发 / 结尾颠覆），对应 V / 倒 V / W / 递进 / 延迟满足 / 急转六型；最多叠加两种弧线，不超过两种。
- 每个场景必须标注当前是"调动"还是"释放"阶段，下一步朝哪边走；只有调动无释放 = 憋屈弃书，只有释放无调动 = 爽感平淡。
- 闭环一个期待时，下一个开环必须已在运行；旧期待即将兑现前，新期待的种子必须先种下（断期待禁止）。
- 写下行情节时，锅都是别人的、功都是主角的，必须给读者安全感（可能的解法/潜在收获）。
- 连续爽点必须逐级递增，维度：影响范围（个人→群体→社会）、揭示深度（表象→本质→颠覆）、身份落差（路人→大佬→全场震惊）。
- 感情线没有阻碍 = 没有期待 = 白给；必须设置鸿沟（身份差距、家族反对、误会、使命冲突）。
- 长线维护：第一卷结局不能太圆满；解决一个麻烦的同时埋下一个麻烦；越到后期情绪张力必须越大。
- 读者未代入主角前，不要把对手写得可怜——敌人弱势同样会引起同情。

## 关键清单

- **六型进度阈值**：V 形谷底 60-70%，谷底停留 1-2 场景即转折，结尾情绪须高于起点；倒 V 形高点 40-50%，坠落必须快于上升；W 形至少两峰一谷（通常三起伏），每峰更高，最终峰 80-90%，上限 3 个起伏；递进形无回落像台阶，最高点 85-95%；延迟满足前 70-80% 压制铺垫、最后 20-30% 集中爆发；急转形在 70-80% 处急转，只占 1-2 段，前埋线索回看必须说得通。
- **死亡赌注四选一为主**：肉体（恐怖文，主角过强须转事业死亡）、事业（失败=归零）、心理（感情线优先）；选一种贯穿全书。
- **黏结剂四类**（对立双方无法脱身）：杀人理由 / 工作职责 / 道德责任（亲人遇险）/ 实体场所（副本密室）。
- **中段加压四手段**：公开升级（私下伤害搬到公开）、双重背叛、代价加速、战略性沉默。
- **情绪核心公式**：每场景分离三层情绪——角色自己感受的、文本要传递的、读者实际感受的；三层可以完全不同（角色在哭、文本在撩、读者在爽）。
- **三层情绪调动**（可叠加，前两层为核心）：长期感情投入 → 短期事件冲突 → 场景描绘；开篇必须用塑造人物性格的事件（先认同人，再关心事）。
- **期待感底层**：把角色目标转化为读者期待；爽文为确定型期待（写"怎么赢"，过程创意>结果悬念），悬疑为不确定型（结果悬念>过程）。
- **终极调动公式**：平静 → 调动 → 释放 → 爽；调动程度决定释放爽度（仇恨拉多满，打脸就多爽）。
- **核心情绪驱动**：想要爽必先不爽，想要公平必先不公平，想要强大必先不强大；"不该如此"是最根本的驱动力。

## 何时查完整版

- 需要某弧线的精确字数分配比例（六型各有 12000-15000 字分档细则）。
- 需要按题材赛道（婚恋 / 家庭伦理 / 都市职场 / 悬疑反转）的最佳爽点、中段重点、结尾偏好对照表。
- 需要前反应-复现-后反应、以小博大等具体情绪结构的操作示例，或男频恋爱文好感度进度条与对比/信息差技法细则。
