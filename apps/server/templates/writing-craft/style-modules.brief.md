# 题材风格模块（精要版）

> 各题材核心规则/技法 + 边界感 + 市场 + 开篇。确定题材后查阅对应模块。本精要只列核心；各题材完整规则/流派细节见 get_craft_doc('style-modules')。

## 题材核心规则速查
- **幽默**：压力释放器（角色维持尊严/权威/冷静但现实不配合）；包袱改变地位/暴露关系/制造代价；余波比包袱重要；回调必须升级。
- **悬疑**：让读者感到问题/危险逼近而答案够不着；每章一个未解问题；靠「问题变贵」非「信息变少」；场景必须清晰。
- **言情**：靠欲望/恐惧/骄傲/误判/情感债摩擦；张力=想靠近+害怕失去；每场关系戏改变信任/脆弱/边界；最动人的亲密藏小事和没说出口的话。
- **推理**：线索公平呈现（读者觉得也能破案）；混在自然叙事中；每真线索旁放 1-2 误导；揭示顺序比真相重要。
- **恐怖**：有限视角（不知道的比展示的怪物更可怕）；恐惧升级；限制信息来源；用生理反应代替直接描写。
- **奇幻/玄幻**：力量体系有边界和代价；世界观跟剧情绑定（不说明文）；日常细节比宏大设定让世界活；金手指碎片化融入。
- **现实/世情**：读者认识这些人（精准日常观察）；对话口语化；场景具体到店名/品牌；矛盾来自真实社会压力（钱/面子/阶层）。
- **升级流/爽文**：升级-收获-装逼三循环；爽点核心=主角牛逼；风轻云淡一指灭杀 >> 歇斯底里艰难取胜；该爽不爽比毒点还毒。

## 边界感（核心）
边界感 = 题材特有的信息点集合，塑造「这就是那个味」。
- 三层：题材边界（设定/节奏/情绪基调）/ 风格边界（语言质感/叙事节奏）/ 受众边界（期待/雷点）。
- 基调一致性：全文基调贯穿，中途改变 = 核心吸引力崩塌。每章自检「和开篇基调一致吗」。
- 缝合：保持一个题材为主基调，另一个提供金手指或外衣；两套节奏交替 = 读者不知道在看什么。

## 各网站风格差异
- 起点主站：升级流/事业线，偏长线期待/世界观深度。
- 番茄：短平快/强情绪/高密度爽点，第一章就要有钩子。
- 刺猬猫：整活>节奏，人设>剧情，动漫同人/二游。
- 下沉：乐子文，颠/搞怪/放飞。

## 开篇五要诀
简单（五要素第一章点明）/ 不偏（符合主线）/ 快（切入快）/ 爽（五章内有震惊）/ 不平（有冲突矛盾）。
- 低位开局核心 = 流畅，信息一点点给，多对话少旁白；金手指在主角积极应对但能力不足时来。

## 正文提示卡三件套
通用正文要求 + 题材正文提示卡 + 本书文风。冲突时：章节细纲 > 题材卡 > 文风 > 通用技巧。

## 质量检查清单
- [ ] 题材边界感（这章是目标题材的味，没串味）
- [ ] 基调一致（与开篇一致）
- [ ] 题材核心技法执行
- [ ] 人设符合标签
- [ ] 对话口语化（现实/世情/升级流强制）
- [ ] 五感细节
- [ ] 开篇五要诀（如检查开篇）
- [ ] 缝合边界感（跨题材主题材为主）
- [ ] 对标书同网站+同题材+同类型

## 何时查完整版
- 需要某题材完整规则（搞笑文/沙雕/赛博朋克/盘点/模拟/直播）、救赎文冲突设计法、低位身份开篇流畅写法、金手指设计要点等细节时。
